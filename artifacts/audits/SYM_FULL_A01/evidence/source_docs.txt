62: ## 2) What the repo is claiming (reviewer framing)
63: 
64: This repository is not only a figure generator. It is designed to make the paper’s structural claims **auditable**:
65: 
66: - **C1** (pure-trace torsion uniqueness): torsion is forced into a pure-trace form, aligned with the compensator gradient (algebraic uniqueness).
67:     
68: - **C2** (three-chain equivalence at quadratic order): three quadratic constructions are bulk-equivalent up to improvement/boundary terms.
69:     
70: - **C3** (tensor-sector locking): the coefficient identity locks **K = G** for the tensor sector, ensuring **two tensor polarizations** and **cT = 1** at quadratic order.
71:     
72: - **NLO / falsifiable forecast**: a small-(k) expansion yields a **slope-2** scaling (toy forecast tooling included as a demonstrator).
73:     
74: 
75: This repo implements the above as:
76: 
77: - paper-checkable identities (symbolic/algebraic checks),
78:     
79: - numerical grids (where relevant),
80:     
81: - artifact generation with integrity hashes (`.md5`),
82:     
83: - and a test suite covering algebra + equivalence + GW sector + script outputs.

382: ## 9) Common reviewer questions (quick answers)
383: 
384: ### Q: “Is this just plotting, or does it actually test the claims?”
385: 
386: A: The repo includes a **full test suite (44 tests)** that covers:
387: 
388: - algebraic building blocks,
389:     
390: - the C1 torsion decomposition/uniqueness,
391:     
392: - the C2 quadratic equivalence checks,
393:     
394: - the C3 tensor-sector locking,
395:     
396: - and figure-script execution consistency.
397:     
398: 
399: ### Q: “What is the single strongest audit point?”
400: 
401: A: `make mixing` (App. D) because it produces a **concrete artifact** (`mixing_matrix.csv` + meta) and **fails** if locking is not met.
402: 
403: ### Q: “What if paper mode fails?”
404: 
405: A: Paper mode is intentionally strict. Failures usually indicate:
406: 
407: - environment mismatch (dependency/version),
408:     
409: - or a code path attempting a fallback that paper mode forbids.  
410:     Run `make paper-test` first to localize the issue.
